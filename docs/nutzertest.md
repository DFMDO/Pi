# Nutzertest: „Person ohne Technikkenntnisse“

**Ziel:** Flashen, Einrichten per QR und ersten Termin anlegen in **unter 15 Minuten** – ohne fremde Hilfe, nur mit dem Anwenderhandbuch.

## Vorbereitung
- Eine Testperson ohne IT-Hintergrund (nicht aus dem Entwicklungsteam), ein Laptop mit Raspberry Pi Imager, eine SD-Karte (≥ 16 GB), ein Pi 4 mit Bildschirm, ein Handy, ein WLAN ohne Internet.
- Image `dfm-signage-arm64-<version>.img.xz` auf dem Laptop. Der Hub ist bereits eingerichtet (Hub-Einrichtung getrennt testen).
- Beobachter notiert, schweigt, hilft nicht (Hilfe nur nach 2 Minuten Stillstand und wird vermerkt).

## Aufgaben und Zeiten
| Nr | Aufgabe | Soll | Zeit | Hilfe nötig? | Beobachtung |
|---|---|---|---|---|---|
| 1 | SD-Karte mit dem Imager flashen („Eigenes Image verwenden“) | ≤ 5 min | | | |
| 2 | Pi einstecken, QR-Code am Bildschirm scannen, WLAN wählen, Rolle „Bildschirm“ | ≤ 5 min | | | |
| 3 | Im Hub „Neuen Bildschirm verbinden“, Code eingeben, bestätigen | ≤ 2 min | | | |
| 4 | Ein Bild hochladen und für morgen 10–12 Uhr planen | ≤ 3 min | | | |
| | **Gesamt** | **< 15 min** | | | |

## Fragen danach
1. Welcher Schritt war am unklarsten? 2. Welches Wort hast du nicht verstanden? 3. Wo hättest du gern ein Bild gehabt? 4. Würdest du dir das allein zutrauen? (1–5)
